# ЖК «Амфітеатр» — лендинг (чистий HTML + CSS, Vite)

Статичний лендинг ЖК «Амфітеатр» (Perspektyva Group), переписаний із генерації
Claude Design у чистий семантичний HTML + CSS під Vite. Призначення — **джерело
правди для дизайну й розробки**: сторінка імпортується в Figma плагіном
[html.to.design](https://html.to.design), DOM стає деревом шарів, а обчислені
стилі — специфікацією. Тому розмітка плоска, значення цілі й зведені на шкали.

## Запуск

```bash
npm install
npm run dev       # дев-сервер → http://localhost:5173/
npm run build     # прод-збірка у dist/
npm run preview   # перегляд зібраного
```

Дві сторінки (multi-page Vite):

| Файл | Призначення |
|------|-------------|
| `index.html` | власне лендинг |
| `styleguide.html` | дизайн-система: токени, типографіка, компоненти та їхні стани |

## Структура

```
index.html              точка входу — лендинг
styleguide.html         точка входу — стайлгайд
vite.config.js          multi-page конфіг
assets/                 зображення (hero, галерея, план, карта)
design-source/          оригінали Claude Design (.dc.html + support.js) — довідка
styles/
  main.css              єдина точка входу (@import усього)
  tokens.css            ВСІ числа як CSS-змінні (єдине джерело значень)
  reset.css             мінімальний скид
  typography.css        класи .text-* + мобільні розміри заголовків
  layout.css            .container, ритм секцій, розміри іконок
  components/
    logo, button, header, breadcrumb, hero, facts, advantages, gallery,
    planning, technology, location, pricing, lead-form, modal, footer,
    chip, styleguide            — один компонент = один файл
```

Правило: у компонентних стилях — **лише `var(--token)`**, жодних магічних чисел і
жодних `style`-атрибутів у розмітці.

## Шкали (де що лежить — `styles/tokens.css`)

**Відступи / розміри** (крок 4/8): `2 4 8 12 16 24 32 40 48 (56) 64 80 96 128`
→ `--space-*`. Менше 16 — кратно 4; від 16 — кратно 8.

**Радіуси:** `2 4 8 12 16 24 9999(pill)` → `--radius-*`.
**Товщина межі:** `1 2` → `--border-*`.
**Іконки:** `16 20 24 32 40 48` → `.icon--*`.
**Висоти контролів:** `24 32 40 48 52 56` → кнопки `--control-h-button` (52),
інпути/степери `--control-h-input` (48), іконо-кнопки `--control-h-icon` (44).

**Типографіка:** розміри `12 14 16 18 20 24 28 32 40 48`, міжрядковий на 4px-сітці
(у px або безрозмірним, де результат цілий). Вага — числом `400 / 600 / 700`.
Шрифт — **Inter** (підключений у `<head>`, ваги 400/600/700), fluid-типографіки
(clamp) немає: різні розміри — медіазапитами на 768 і 1200.

**Кольори** зняті під сайт-приймач `perspektyva.com.ua`: ink `#23262D`,
бренд-жовтий `#FFC000`.

Повний перелік значень поза шкалами (і чому) — у `OUT-OF-SCALE.md`.

## Брейкпоінти

| Діапазон | Що |
|----------|-----|
| `< 768` | мобільний |
| `768 – 1199` | планшет |
| `≥ 1200` | desktop |

Шапка перемикається desktop/мобільний на **1200**, не на 768.

## Імпорт у Figma (html.to.design)

1. `npm run dev` і відкрити `http://localhost:5173/` (або `/styleguide.html`).
2. У плагіні html.to.design вказати URL сторінки (або вставити HTML).
3. Імпортувати. DOM стане деревом фреймів, обчислені стилі — спекою.
4. Повторювані блоки (fact-card, advantage-card, plan-card, price-card, chip,
   btn) мають однакову структуру й класи — з них зручно зібрати компоненти.

Спочатку імпортуйте `styleguide.html`, щоб завести у файл токени/типографіку/
компоненти, потім `index.html` як складену сторінку.

**Що не переноситься в експорт** (і чим замінено) — див. `OUT-OF-SCALE.md`,
розділ «Втрати при експорті». Коротко: сторінка статична (без JS); каруселі
показують перший кадр; карта — статичне фото замість Google-iframe; паралакс і
pulse-анімація прибрані; фільтри/блюр і фокус-кільця в експорт не йдуть.
